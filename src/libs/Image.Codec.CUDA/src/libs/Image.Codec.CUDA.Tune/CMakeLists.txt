# 参数扫描库：在自己的硬件上找到最优编码参数（tile / 批大小 / block 线程 / 滤波策略）。
#
# 只依赖各 codec 模块的 C++ 入口（不经过 C API），因此测量的是编码本身，
# 不含 C API 为了 ABI 稳定而做的那一次 host 缓冲复制。

  src/tune.h
  src/tune.cpp)

  "${CMAKE_CURRENT_SOURCE_DIR}/src")

  Image.Codec.CUDA::Core
  Image.Codec.CUDA::Common
  Image.Codec.CUDA::Tiff
  Image.Codec.CUDA::Png
  Image.Codec.CUDA::NvJpeg
  Image.Codec.CUDA::Metrics)

# 命名空间别名：target_link_libraries(app PRIVATE Image.Codec.CUDA::Tune)
add_library(Image.Codec.CUDA::Tune ALIAS Image.Codec.CUDA.Tune)
